# React/Vite prototype

Static Requester dashboard prototype. Sample data and toast-only actions; no production API, authentication, or request workflow. See repository [implementation status](../../docs/progress/implementation.md) and [design coverage](../../docs/design/screens.md).

## Run locally

From `prototype/react-dashboard/`:

```sh
npm run dev
```

For the verified local bind/port:

```sh
npm run dev -- --host 127.0.0.1 --port 4177
```

## Commands

- `npm run dev`: Vite development server.
- `npm run build`: Vite production build.
- `npm run lint`: Oxlint.
- `npm run preview`: preview build output.
